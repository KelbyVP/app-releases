# Kelby's Christmas (Windows)

**Install:** download [KelbysChristmas-Setup.exe](https://raw.githubusercontent.com/KelbyVP/app-releases/main/kelbys-christmas-win/KelbysChristmas-Setup.exe) and run it.

- Installs silently under `%LocalAppData%\KelbyVP\KelbysChristmas\app` (no admin)
- Starts the app when done
- Later updates apply themselves with no popups

Version **0.1.3**
